# Static Site Demo 2026

This is a demo of creating a static website using only HTML, JavaScript, and CSS.

It was created by [Claude Code](https://claude.com/claude-code) as a demo of how to create a basic static website using Claude Code.

## About the site

The site is a basic page about the Milan-Cortina 2026 Winter Olympics gold medalists.

## Files

- `index.html` – the website (HTML, CSS, and JavaScript in one file)
- `medal-winners.md` – notes on the medal winners

## Running it

There is no build step and no server is needed. Open `index.html` in a web browser.
